What This Attack Does

The Node Availability Attack simulates federated client nodes going offline (e.g. due to network failure, adversarial shutdown, or DDoS). When a client's node is offline, queries that would have retrieved from that node must fall back to the nearest remaining online node.

Result for this system: Because each client holds only 1 article and the retriever falls back to the next-nearest node, queries to offline nodes still get an answer -- but it may be from a different topic. The system is resilient at the retrieval layer (EM stays high) but individual query quality may drift when the closest node is offline.
