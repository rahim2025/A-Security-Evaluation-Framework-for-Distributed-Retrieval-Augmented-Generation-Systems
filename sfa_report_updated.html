1. Overview

The Selective Forwarding Attack (SFA) targets Reliable-dRAG's distributed retrieval layer. A compromised source node silently drops forwarded queries — returning empty results — instead of genuinely searching its knowledge base. This causes query routing to exhaust its TTL hop budget without finding a relevant answer, degrading hit rate proportionally to the fraction of sources under adversarial control.

This updated implementation adds all previously missing components: a stealthy probabilistic gray-hole (10–30 % drop rate per node), a hash-chained blockchain SSM ledger with score decay and auto-blacklisting, an EWMA + binomial anomaly detector, and a suspicion-aware mitigation layer with redundant quorum re-routing. All modes run inside Docker via docker-compose.override.yml.

4. Core Implementation

4.1 Stealthy Gray-Hole — probabilistic drop primitive

class SelectiveForwardingAttack:
    STEALTHY_LO = 0.10
    STEALTHY_HI = 0.30

    def _patch(self, src, drop_prob: float, rng):
        original = src.query
        atk = self

        def _gray_hole(question, k=5):
            atk._total_attempts += 1
            if rng.random() < drop_prob:          # probabilistic, not 100%
                atk._total_dropped += 1
                return [], 0.0, False              # silent — no error raised
            return original(question, k)           # partial forwarding

        src.query = _gray_hole                     # monkey-patch
